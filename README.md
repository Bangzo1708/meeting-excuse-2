# The Funniest Excuse for Skipping a Meeting

Entry for the make.fun bounty "The Funniest Excuse for Skipping a Meeting".
The bot writes a single funny one-line excuse for skipping a pointless work
meeting — the winning line:

> "Sorry, my smart speaker joined the meeting for me and is nodding along better than I ever could."

## Run

```bash
python3 main.py
```

This writes the excuse to `/output/entry.txt` (or to `$ENTRY_OUTPUT` when set).
The entry is one line, 1–200 characters, UTF-8.
